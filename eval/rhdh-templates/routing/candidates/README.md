# Candidate routing cases

Use AEH dataset-generation facilities to draft prompts that fill gaps in the
reviewed routing matrix. Write generated output to a temporary directory or
this candidate area; do not overwrite `../cases`.

A maintainer must review the prompt, `should_trigger` annotation, rationale,
style, and judge contract before copying a candidate into `../cases`. Generated
cases do not count toward routing coverage or pilot results until promoted.
